# Brightcove GraphQL API

Brightcove is a cloud video platform for businesses. The API covers video ingestion and management, player configuration, dynamic delivery, analytics, social sharing, live streaming, video cloud CMS, audience data, and monetization.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Brightcove REST API
**Documentation:** https://apis.support.brightcove.com/

- Reference: https://apis.support.brightcove.com/cms/references/cms-api-swagger.yaml
- Schema: https://github.com/api-evangelist/brightcove
